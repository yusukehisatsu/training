# 2026-11-03 ゴルフレッスンフィードバック

## 原文

# アイアン
- グリップエンドから拳一個半ぐらいの距離感を意識する

# アプローチ
- 体とクラブヘッドが同じスピードになるようにする、かつかなり遅めのスピードでよい
  - ここを固定することにより、距離感を安定させる
 - フェースが開く傾向があるので、以下のことに気をつける
  - ハンドファーストになるよう左手の屈曲をキープする
  - バックスイングの際に手前に引かない（まっすぐ上げる）
- フェースが寝すぎて潜ってしまうことも多いので、ロフトを立てるイメージも持つ
- トップ防止のために芝の上を滑らすイメージを持つ
  - そのために右手のリリースを打ってからにする、つまりインパクトの時点ではまだ曲がっている状態
  - 結果として、インパクト時点ではかなり右に屈曲している状態が正解
  - ただし、右足に体重が乗ってはいけないので注意
- 高く上げたくない時、サンドウェッジで低く打てるようにする（９番とかを使わない）
  - なぜなら、サンドのほうがスピンが計算できるので、転がりすぎを防止できる
  - 低く打つには、ボールを右足寄りに置き、アドレスの際のハンドファーストをキツめにする
