# ゴルフ

## 症状から見直す項目 〔推論〕

> 球の出方から「どの項目を見直すか」への対応表。指導内容から導いたもので、コーチに確認済みではない。

| 球の症状 | まず見直す項目 |
| --- | --- |
| 右に打ち出して左に戻る | **狙いどおりのドロー**。この方向で合っている |
| 右に打ち出したまま戻らない | ダウンスイング（フェースのローテーションが間に合っていないか）／テイクバック（腰の高さでフェースが空を向いて開いていないか）／グリップ（左手が元の握りに戻っていないか） |
| 左に打ち出す（引っかけ） | フェースが閉じすぎているか、軌道が左を向いている。フェースのローテーションを弱める |
| トップ・ダフリが混ざる | アドレス（前傾が浅くないか）／フォロースルー（左膝が伸びて起き上がっていないか）／右手で打ちに行っていないか（人差し指を離せているか） |

## スイングの流れ

**グリップ → アドレス → テイクバック → トップ → ダウンスイング → インパクト → フォロースルー → フィニッシュ**。項目はこの順に並べる。まだ教わっていない項目は置いていない。

## グリップ

### 左手

- **今までよりストロングに**握る
- 親指と人差し指の間にできる**線（V 字）が右肩を指す**
- **避ける形〔推論〕**：V 字が顎や右耳の方を指す元の握りに戻る

### 右手

- **手のひらの向きをフェースの角度と合わせる**
- **人差し指はグリップから離す**。役割は「クラブが落ちてくるのを支える」ことで、握り込まない
- **避ける形〔推論〕**：人差し指で握り込む／右手でクラブを操作しに行く

### 確認方法・狙い 〔推論〕

- 構えたら**真上から見下ろして V 字の向き**を毎回チェックする（鏡や動画がなくても確認できる）
- 右手は**手のひらをフェース面に当ててから、そのまま握りに移す**と角度が揃いやすい
- 3 つの修正（ストロング・手のひら＝フェース・人差し指を離す）は、いずれも**フェースを開かせない／右手を使わせない**方向で一貫している

## アドレス

- **今までより深く構える**
- **ベルトのバックルがボールを向く**
- **骨盤の上に乗っている感覚**で立つ
- **膝は今までより曲げてよい**
- **もう少しグリップエンドに近づく**（アドレス自体は安定してきている）
- 狙い：この構えができると**フォロースルーを飛球方向に長く維持できる**
- **避ける形〔推論〕**：立ち気味で腰の位置が高い／**腰を反らせてバックルを下に向ける**（股関節ではなく腰椎で前傾を作る）

### 体との接点・確認方法 〔推論〕

- **反り腰の癖があるため、バックルをボールに向けようとして腰椎を反らせやすい**。反った前傾は股関節の回旋を制限し、インパクトで起き上がる動き（早期伸展）と腰への負担につながる。前傾は**膝から曲げず、股関節から尻を後ろに引いて**作る（ルーマニアンデッドリフトと同じヒンジ）
- コーチの「骨盤の上に乗っている感覚」は、この反りを防ぐキューと読める
- 確認は**飛球線後方からスマホで撮影**し、背中が一直線で腰が反っていないか、膝が曲がっているかを見る

## テイクバック

- **腰の高さの時点で、フェースの角度と背中の角度を同じ**にする（**左手でコントロール**）
- **フェースと垂直な状態を可能な限り維持**しながら引く（上の「腰の高さ」チェックが具体的な基準）
- **コックは可能な限り入れない**
- **避ける形〔推論〕**：腰の高さでフェースが空を向く（開く）／手首を早く折って上げる／右手で持ち上げる

### 確認方法 〔推論〕

- **飛球線後方から撮影**し、シャフトが地面と平行になった瞬間で止めて、フェースの向きが背中の角度と揃っているかを見る
- 鏡が正面にある打席なら、腰の高さまでゆっくり引いて止め、フェースの向きを目で確認してから戻す素振りを数回入れる

## ダウンスイング

- **フェースのローテーションを強く意識する**。リリースで両手を右斜前方へ伸ばすとフェースはオープンになるため
- 目安は**右足を通過するあたりでクラブが手を追い越す**レベル
- 感覚としては**野球のスイングに近い**
- **避ける形〔推論〕**：ローテーションが間に合わず、フェースが開いたままインパクトに入る／手元だけが先行してクラブヘッドが遅れて出てくる

## インパクト

> 目指すのは**ドロー**。次の 4 つが揃った状態。

| 項目 | 目指す状態 |
| --- | --- |
| 軌道 | インサイドアウト |
| フェース | クローズ |
| 打ち出し | 右方向 |
| スピン | マイナス |

- **〔推論〕** 「スピンがマイナス」はスピン軸が左に傾いた状態を指す。打ち出しが右・軸が左で、**右に出て左に戻る**弾道になる

## フォロースルー

- **リリースで両手が右斜前方に伸びた状態を作り、そこで止める**意識を持つ。これが**エネルギーを 100% 解放した状態**
- **リリースの時点で頭が前に動かず、その場に固定されている**ようにする（**側屈の意識を強く**）
- **左膝が伸び切らないようにする**。**アドレスの低い姿勢をリリースまで維持する**
- **避ける形〔推論〕**：両手が体の左へ巻き込まれて抜ける／頭が前に流れる／左膝が伸びて体が起き上がる

### 確認方法 〔推論〕

- **正面から撮影**し、リリースの瞬間で止めて、頭がアドレスの位置から動いていないかを見る
- 同じ映像で**左膝が曲がったままか**、腰の高さがアドレスから上がっていないかを確認する

## 練習法

- **インドアゴルフ**：ボールの**左下と右上にもう 1 球ずつ置き**、インサイドアウトでないと当たってしまう状態にして打つ
- **〔推論〕** 置いたボールに当たるのは軌道が外から入っている（アウトサイドイン）サイン。当てずに打てていればインサイドアウトの軌道が出ている

## 体づくりとの接点 〔推論〕

ジムメニューとゴルフは同じ方向を向いている。

- **中臀筋**（ヒップアブダクター）：左股関節に乗って回り切るための土台。骨盤が横に流れるのを止める
- **胸椎の回旋**（オープンブック）：バックスイングの回転量。腰を回さずに胸だけ回せる範囲がそのまま使える
- **ハムストリングと股関節ヒンジ**（ルーマニアンデッドリフト・片足股関節デッドリフト）：深い前傾をスイング中ずっと保つ能力
- **肩甲骨下制**：肩の力みを抜いたアドレス。肩がすくむと腕でクラブを上げる動きになる
