- パーソナルトレーナーが過去に自宅でやるように指示したトレーニングメニューの一覧

## メニュー
- [ ]  バタフライ
    - やり方
        - 仰向けになって肘を垂直に立てる
        - 腕と足を同時に広げて地面まで
        - 肩甲骨を下げるイメージで
- [ ]  ウォールスライド
    - やり方
        - 壁に背中と腕をつけ、**肘90°のW姿勢**を作る。
        - **肩甲骨を下げたまま**腕を壁に沿ってゆっくり上へ滑らせる。
        - 腰を反らさず、**肩をすくめない状態で元の位置に戻す。**
- [ ]  [ヒップリフトもも裏](https://www.youtube.com/watch?v=28iHvEVCuv8)
    - やり方
        - ポールを横にして両足のかかとを乗せる。背中を地面につけるようにインナーマッスルに力を入れた状態で骨盤だけ上に上げる。その際にも裏に力が入ってるように意識する。
- [ ]  [デッドバグ](https://www.youtube.com/watch?v=GabK_6ke6LU)
    - やり方
        - 縦にしたポールの上にの仰向けで乗り、前並えをする。片足を上げ、90度にし、その足とハンターの手を伸ばしながら腹筋を鍛える、その際に背中がポールから離れないようにインナーマッスルに力を入れる
        - やり方
            - 横にしたポールに両手を置き、腰を逸らさず、肘を多少内側に捻り、肩から力を抜いて、肩甲骨をまっすぐにし、そこから片腕ずつ上げる
            - その際に肩甲骨と腰の位置が変わらないように、しっかり残った腕を押し、腹筋に力を入れてキープする
            - 肩や鎖骨あたりに力が入らないように
- [ ]  [キャットキャメル](https://www.youtube.com/watch?v=G5r-gYSLSV8)片手ver
    - やり方
        - ポールを横にして両手をつき、息を吐きながら、肩甲骨を丸める。その際に、小指側に力を入れる
        - 丸め切った後に膝を上げて、腹筋に力を入れる
        - 膝とポールの距離を短くして伸ばす肩甲骨の場所を変える
        - 片手を水平に上げて45度前半に伸ばす
- [ ]  プッシュアップ（大胸筋下部）
    - やり方
        - ポールの上に手を乗せ、指はつけずに手首の外側で押すように（手で弧を描くイメージ）
        - 不安定さによりインナーマッスルを鍛える
        - 上がる時に押し切る
        - 腰は丸まるように
- [ ]  プッシュアップ（大胸筋上部）
    - やり方
        - ポールの上に足を乗せ、腕を押し上げるイメージ
- [ ]  ダウンドッグ
    - やり方
        - ロールアップダウンをした流れで手で歩く
        - プッシュアップの状態から腰を上げ、腰→背中→腕が一直線になるように（頭も両腕の間に入るように）
        - 足踏みをしてふくらはぎを伸ばす
        - 前に歩いてロールアップダウンの逆をやって戻る
- [ ]  オープンブック
    - やり方
        - 書けないので覚える
- [ ]  上腕三頭筋トレーニング
    - やり方
        - 膝を伸ばして座り、指を前に向けて手をつく（幅は肩幅、わきが締まるぐらい）
        - 息を吐き胸を張りながら腰を浮かして体がまっすぐになるところまで
            - その際に腰を反らないように気を付ける
        - その状態から片足ずつ上げる
- [ ]  ベアクロール
    - やり方
        - 四つん這いになって背中を丸め肩を押し出す
        - 右手と左足、左手と右足のように交互に出して前後に歩く
        - 膝は地面スレスレ
        - 背中が反らないように気を付ける
        - 着地の時から肩甲骨を押し出す意識
        - 戻る時はグッと押し出して
- [ ]  スパイダーウォーク？
    - やり方
        - ベアロールの逆
        - 僧帽筋下部を意識する
        - 肩甲骨を下げる意識
- [ ]  サイドプランク・ウィンドミル
    - やり方
        - サイドプランクの姿勢で、右手を地面につけて、左足を前に
        - カールしながら左手で右足首を触りに行く
        - 尻を高く上げる
- [ ]  アブローラー
    - やり方
        - 首を伸ばして、腹筋を丸めた状態で肩甲骨から前に出すだけ（自慢スレスレを目指す必要はない）
- [ ]  チューブローイング
    - やり方
        - 足にチューブをかけて引く
        - 三角筋ではなく広背筋に力が入ってる状態を意識する
        - 最初のうちは反対の手で広背筋を触りながらやるのが良い
- [ ]  チューブYロー
    - やり方
        - チューブを持ち、腕を **肩よりやや上のY字（約45°）方向**に伸ばす。
        - **肩をすくめず肩甲骨を下げる意識**で、チューブを引く。
        - ゆっくり戻し、**首ではなく背中（僧帽筋下部）に効かせる。**
- [ ]  内腿スライド
    - やり方
        - フローリングでタオルを敷いて足を広げる
        - 常に二等辺三角形になるように、等速で動く
- [ ]  デッドリフト（練習）
    - やり方
        - 最終的に肩甲骨が下がった位置で、骨盤が後傾している（クリスティアーノ・ロナウド）
        - つま先はまっすぐ（ガニ股にならない）
        - そのまま下げてハムストリングが伸びてる状態（膝を曲げすぎない）
- [ ]  壁背骨（ロールアップダウン）
    - やり方
        - 壁に背中をつけて前屈、背骨を1つずつ動かすイメージ、背骨は24個あるのでそのイメージで。
- [ ]  腹式呼吸ストレッチ
    - やり方
        - 土下座のような姿勢で腹部で呼吸→腰を内圧をかけてストレッチ
- [ ]  壁肩甲骨スクワット
    - やり方
        - 壁から5cm離れて足を外側45度にし、胸を壁につけ、腕は高く上げ、膝を曲げた状態で深呼吸を3回
        - 僧帽筋の下の方を意識する
- [ ]  腰回り筋トレ（クラムトーニー）
    - やり方
        - 横向きに寝て、下側の腹部を地面から上げて、膝は90度で壁を押し、背中は丸まり、下側の股関節を挟むために上側の足を前にずらす、上側の膝を上げてお尻活性、下側の膝も床から上げて内転筋活性
        - 腰を丸めて上の足を前に動かすだけで下の足の内腿に刺激は来るはず
- [ ]  椅子に乗って反る
    - やり方
        - 足を椅子に乗せて膝を曲げる
        - プッシュアップの状態から腰を上げ、腰→背中→腕が一直線になるように（頭も両腕の間に入るように）
        - 膝は曲げたままでオッケー
- [ ]  レッグ腹筋
    - やり方
        - 膝の裏にクッションを挟む
        - 脚を上げて縮こまり、ゆっくり脚を下ろす（背骨を一つずつ付けるイメージ）
- [ ]  サイドプランク
    - やり方
        - 上側の足を前に出すとヘソが上を向かないので、負荷は下がるが安定はする
- [ ]  体を折る
    - やり方
        - 肩から肋骨にかけて線を引いて、そこで谷折りするイメージ
        - 体はツイストしないように
        - 脇腹に力が入ってる状態
        - 肋骨が柔らかくなる
- [ ]  膝強化
    - やり方
        - 何か重いものを持って右足を前に出す
        - 踵で着地をし、足の指が地面に対して平行な状態をキープする
        - その際上半身は前傾姿勢
- [ ]  左右バランス矯正
    - やり方
        - あぐらをかいて両手を床につける
        - 床を押しつつ右の脇腹を伸ばすイメージ
- [ ]  僧帽筋可動
    - やり方
        - 脇を締めて腕がWのようになるように手を後ろに下げる
        - チューブを使えたらなおよし
- [ ]  肩インナーマッスル3セット
    - やり方
        - 全てにおいて「肩甲骨を下ろす状態」でやることを意識する（肩が前に入ってる状態だとアウターマッスルしか使えない）
            - 左右バランス矯正をやってる状態がそれ
            - 反り腰にならないように
        - 仰向けになって脇を締めて肘を90度に立て、左右に引っ張る（棘下筋に力が入ってる状態）
        - 仰向けになって脇を締めて肘を90度に立て、内側に引っ張る（小胸筋に力が入ってる状態）
            - 代わりに、腹の上にクッションを置いてそれを押すでも良い
            - その際に膝の下にタオルなど敷いて高さをつける（肩の真下に肘がくる姿勢を作りたい）
        - 立って腕を下ろして右に引っ張る（僧帽筋に力が入ってる状態）
- [ ]  腰横ストレッチ
    - やり方
        - 骨盤は起こしたまま（ボールが入ってるイメージ）横に倒れる
- [ ]  胸伸ばし
    - やり方
        - 仰向けに寝て右手で何かを掴み、右足を左下に伸ばす
        - 右手を上に力をいれ、肘を地面からつけないようにして胸を伸ばす
        - 動く時は一気に動くのではなく、パーツごとに徐々に動いていく
- [ ]  肩伸ばし
    - やり方
        - 何かを掴んで肩を丸めて外側を伸ばす
- [ ]  骨盤矯正＋肋骨伸ばし
    - やり方
        - チューブを土踏まず、背骨を伸ばして膝を曲げ、腰を反らずに左足に体重を乗せる
        - その際に体をそちらの方に捻ることで、左の尻にかなり力が入る
        - この状態で右足を真横に出して戻す
        - かつ、左手の手のひらを自分側、右手の手のひらを外側に向けて組み、右肩を額のあたりまで持っていき上下に引っ張る
- [ ]  壁スクワット（上級）
    - やり方
        - 10cmぐらい離れて膝を曲げ、肩を丸める
        - 肩と同じ高さで肘を壁につけ押し付ける
        - 骨盤を反るのではく丸めることが大事
- [ ]  僧帽筋トレ
    - やり方
        - みぞおちにマットを置く
        - うつ伏せで手は前方、僧帽筋下部辺りから反っていく（腰からではない）
        - 手を引いていって僧帽筋に力が入っていることを感じる
        - 手を前方に戻して終わり
- [ ]  肩甲骨スタビリティ
    - やり方
        - ポールに両手を乗せて片手・片足ずつ上げる
        - 体の水平さを維持するよう、支えてる手でしっかり地面を押す（肩甲骨にしっかり力が入っているかどうかチェックする）
            - 今は右にうまく力が入ってないらしい
        - ポールを背中に乗せて落ちないレベル
- [ ]  腕を引くやつ
    - やり方
        - 左足を前、右足を後ろで指を立て、左の尻に力を入れた状態で前傾姿勢になる
        - 右手でチューブを持って膝の力を使わず、肩甲骨で引く
        - 肩を下げて胸を張り、肩甲骨を内側かつ下に動かすイメージ

- [ ]  腹筋と胸筋連動
    - やり方
        - 膝を立てて腹筋の準備の姿勢（太ももに何か挟むと内腿のトレーニングにもなる）
        - 起き上がりつつ、左を向く（体を起こし切らずつらいところで止める）
        - 右手は左膝の横、左手は可能な限り後ろまでもっていく
            - その際に肩を動かすのではなく肩甲骨を動かすことを意識する
            - 肘を曲げたほうが肩甲骨が下がりやすくなる
- [ ]  新呼吸法
    - やり方
        - 吸う時に胸と腹の両方が膨らむように
        - 肩は上がらないように
        - 肩甲骨を動かすことが目的
- [ ]  肩筋肉ほぐし（マッサージガン）
    - やり方
        - 肩周りの筋肉が硬すぎるのでほぐす
